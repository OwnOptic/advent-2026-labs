# Power Platform Advent Calendar 2026 labs

Step-by-step labs for Elliot Margot's three Advent Calendar 2026 videos, published at
https://ownoptic.github.io/advent-2026-labs/ (short link: https://e-margot.ch/lab).

- `vibe-coding/` - Let's vibe code a Copilot Studio agent together (Claude, Azure command-line interface, Microsoft Copilot harness)
- `failures/` - Agents that died in production: the ghosts of agents past
- `triggers/` - Copilot Studio triggers: Christmas supplier documents

Contoso, Fabrikam, Litware and Northwind are fictional companies; every document here is an example.
